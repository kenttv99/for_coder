# HeroSection Component

## Overview
A stunning and unconventional first section for the yacht rental website in Sochi. This component features an immersive water-themed design with interactive elements that respond to user input.

## Features
- Animated water background with multiple layers
- Interactive yacht elements that follow mouse movement
- Floating information cards with yacht details
- Wave animations at the bottom of the section
- Responsive design for all screen sizes
- Modern CSS techniques including backdrop-filter, gradients, and animations

## Design Elements
- **Water-themed background**: Multiple animated layers creating a realistic water effect
- **Interactive yachts**: Yacht images that respond to mouse movement and can be selected
- **Floating cards**: Information cards that slide in when a yacht is selected
- **Wave animations**: Subtle wave patterns at the bottom for added visual interest
- **Glass-morphism**: Backdrop blur effects for modern UI elements

## Technical Implementation
- Built with React and modern JavaScript
- Uses CSS modules for styling isolation
- Implements mouse tracking for interactive effects
- Follows clean architecture principles
- Fully responsive design

## Customization
- Yacht data can be easily modified in the component state
- Colors and animations can be adjusted in the CSS file
- Layout can be modified through CSS variables and classes

## Dependencies
- React (v18+)
- Modern browser with CSS backdrop-filter support
